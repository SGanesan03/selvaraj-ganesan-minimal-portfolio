# Selvaraj Ganesan — Minimal Senior Frontend Developer Portfolio

Clean, typography-focused portfolio built with React, TypeScript, and Tailwind CSS, strictly aligned with resume experience.

## Deploy to `https://sganesan03.github.io/`
1. Create a public GitHub repository named `sganesan03.github.io`.
2. Push this folder to the `main` branch.
3. In GitHub **Settings -> Pages**, set **Source** to **GitHub Actions**.
4. The included `.github/workflows/deploy.yml` builds and publishes automatically.
